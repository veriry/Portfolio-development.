# Barbershop — программа учёта записей барбершопа

Настольное приложение (WPF, .NET Framework 4.8) для ведения клиентов и записей на визиты в барбершопе. Данные хранятся в базе Microsoft SQL Server. Администратор и барберы работают в отдельных окнах, а по каждому визиту можно сформировать чек в формате Word.

## 1. Что нужно для работы

| Компонент | Требование |
|---|---|
| Операционная система | Windows 10 (версия 1903 и новее) или Windows 11 |
| .NET Framework | 4.8 (в указанных версиях Windows уже установлен) |
| Microsoft SQL Server | Установлен как **экземпляр по умолчанию** (подключение к `.`). SQL Server Express с именем `SQLEXPRESS` и LocalDB без изменения настроек не подойдут |
| Microsoft Word | Нужен для формирования чеков и отчётов. Без него остальные функции работают |
| Права | У пользователя Windows должен быть доступ к SQL Server (подключение выполняется под текущей учётной записью Windows) |

## 2. Состав папки программы

Копируйте папку целиком, а не один exe-файл:

- `Barbershop.exe` — запуск программы
- `Barbershop.exe.config` — настройки подключения к базе
- `EntityFramework.dll`, `EntityFramework.SqlServer.dll` — библиотеки доступа к данным
- `Чек_Барбершоп.docx` — шаблон чека (должен лежать рядом с exe)
- `script_full.sql` — скрипт создания и наполнения базы данных

> Запускайте программу двойным щелчком по `Barbershop.exe` из её папки. Если запускать через ярлык с другой «рабочей папкой», шаблон чека не будет найден.

## 3. Первый запуск и база данных

**Вариант А. Автоматически.** Если в вашей сборке программы включено автоматическое создание базы, достаточно запустить `Barbershop.exe`. При первом запуске будут созданы база `Barbershop`, все таблицы и тестовые данные. При повторных запусках данные не дублируются и не изменяются.

**Вариант Б. Вручную (один раз).**
1. Откройте SQL Server Management Studio и подключитесь к серверу.
2. Откройте файл `script_full.sql` и нажмите **Выполнить** (F5).
3. Убедитесь, что в обозревателе объектов появилась база `Barbershop`.
4. Запустите `Barbershop.exe`.

Если SQL Server находится на другом компьютере или имеет имя экземпляра, откройте `Barbershop.exe.config` в Блокноте и в строке подключения замените `data source=.` на нужное значение, например `data source=ИМЯ_ПК\SQLEXPRESS`. Строк подключения две (`BarbershopEntities` и `BarbershopEntities1`), меняйте в обеих.

## 4. Вход в систему

1. Введите логин и пароль.
2. Введите символы с картинки (капчу).
3. Нажмите кнопку входа.

Что нужно знать:
- При неверном логине или пароле выводится сообщение «Неверный логин или пароль!».
- При неверно введённой капче выводится сообщение «Капча была введена неверно!», а интерфейс блокируется на 10 секунд. Дождитесь окончания блокировки и повторите ввод.
- После успешного входа открывается окно, соответствующее роли пользователя: **Администратор** или **Барбер**.
- Если роль не распознана, выводится сообщение «Роль пользователя не распознана». Обратитесь к администратору.

### Тестовые учётные записи

Если база создана скриптом `script_full.sql`, доступны следующие учётные записи:

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Барбер | `barber1` - `barber2` | `pass1`- `pass2` |


## 5. Работа в программе

### Администратор
- **Клиенты.** Просмотр справочника клиентов, добавление нового клиента, редактирование данных и удаление. При добавлении обязательно заполните поля «Имя» и «Фамилия». Дату рождения вводите в формате `ДД.ММ.ГГГГ`.
- **Записи (визиты).** Просмотр списка записей, открытие карточки записи, изменение статуса, отмена и удаление записи. Перед удалением программа запрашивает подтверждение.
- **Чек.** Для выбранной записи можно сформировать чек в Word.
- **Отчёт.** Формирование финансового отчёта в файл Word. Имя файла имеет вид `Отчёт_<тип>_ддММгггг_ЧЧмм.docx`, а после создания программа показывает путь к сохранённому файлу.

### Барбер
- Интерфейс в данный момент в разработке

### Статусы визита
В тестовой базе используются статусы: **Ожидается**, **Завершён**, **Отменён**, **Не явился**. Новые записи по умолчанию создаются со статусом «Ожидается».

### Чек
Чек формируется по шаблону `Чек_Барбершоп.docx` и содержит данные клиента (фамилия, имя, телефон), номер визита, дату и статус, название услуги, длительность в минутах и итоговую стоимость в рублях. Для этого на компьютере должен быть установлен Microsoft Word.

## 6. Тестовые данные

Скрипт `script_full.sql` создаёт для демонстрации:
- 2 роли, 5 специализаций, 4 типа услуг, 4 статуса;
- 11 услуг с ценой и длительностью;
- 6 сотрудников (1 администратор и 5 барберов);
- 25 клиентов;
- 183 записи со статусом «Ожидается»: по 3 в день на 2 месяца вперёд от даты первого запуска. Время визитов — только на `:00` или `:30` в промежутке 09:00–21:00, между визитами одного дня не менее 40 минут.

Все имена, телефоны и пароли в тестовых данных вымышленные.

## 7. Возможные проблемы

| Проблема | Что делать |
|---|---|
| При запуске ошибка подключения к базе | Проверьте, что SQL Server запущен (служба `SQL Server (MSSQLSERVER)`), что база `Barbershop` создана и что в `Barbershop.exe.config` указан правильный сервер |
| «Не удалось подготовить базу данных» | Проверьте права пользователя Windows в SQL Server и наличие файла `script_full.sql` рядом с программой |
| Не создаётся чек или отчёт | Убедитесь, что установлен Microsoft Word и что файл `Чек_Барбершоп.docx` лежит рядом с `Barbershop.exe` |
| Не могу войти | Проверьте раскладку клавиатуры и регистр, введите капчу заново. При блокировке подождите 10 секунд |
| Программа не запускается совсем | Убедитесь, что установлен .NET Framework 4.8, а в папке есть все файлы из раздела 2 |
